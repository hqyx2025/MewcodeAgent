# M06 验收记录

日期：2026-10-06。实际平台：Windows11专业版、Node.js24.14.0、npm11.9.0。默认测试全部使用Mock/模拟服务与自建临时目录，没有调用收费模型。

## 功能、错误与边界

| 项目 | 实际验证 |
| --- | --- |
| 来源与持久规则 | 用户/项目规则累积、重新加载保留，空数组和CLI模式不能清除deny；项目accept-edits不提升用户模式 |
| 策略优先级 | Plan、工具deny、路径deny、ask、可信文件allow和默认策略；项目allow与用户shell allow不能自动执行shell |
| 路径与搜索 | 规范相对/绝对目标、目录边界、Windows大小写；Glob/Grep与禁止目录相交在准备/读取前拒绝，缩小范围后成功 |
| 自动指令 | ReadFile路径deny保护指令，ask指令不自动加载或泄漏正文，prompt显示PERMISSION诊断 |
| 会话授权 | 相同参数调用两次仅审批一次；命令/复合语法、cwd、预览、模式变化重新审批；原调用参数和审批对象冻结 |
| 一次授权与拒绝 | once每次询问；拒绝不执行、不缓存；非TTY拒绝ask；明确--approve仍无法覆盖deny |
| 继承与切换 | 子执行器不能提升模式、替换shell/rg、取消父审计；父规则与后来收紧生效；审批期间模式切换被拒绝 |
| 审批后变化 | 原M03回归继续验证版本变化、并发创建和junction置换不覆盖文件，取消后迟到批准不执行 |
| 超时与取消 | 挂起审批/审计受工具总时限约束，取消不执行；原shell超时、退出、子进程清理回归继续通过 |
| diff展示 | 精确替换显示上下文、删除行与新增行；最大4096bytes，截断标记；输入与revision仍完整参与授权指纹 |
| 审计 | 内存快照不被外部改写；原命令、内容、绝对路径和原callId不进入日志；记录来源、摘要、cache hit和授权方式 |
| 持久审计故障 | 新文件独占创建、串行JSONL、已有文件/链接父目录拒绝；故障阻止文件写入且不回显底层敏感错误 |
| CLI与安装 | permissions无需模型密钥；run JSONL与文件决策一致；工具不能读活动审计文件；只安装生产依赖验证命令与bin |
| 核心MVP | M04搜索→读取→修复→执行测试→汇报模拟闭环、错误修正、Plan和M05恶意项目指令回归均在本次完整检查中通过 |

## 测量与调优

`npm run bench:permissions`，Windows Node24.14.0，5次样本；400规则、每次10000决策，含循环与正确性断言，中位187.97毫秒，约18.80微秒/决策。不同路径覆盖allow/ask/deny，不包含文件系统或模型/网络。

两组各100次相同参数模拟shell调用：once审批100次、中位6.09毫秒；session审批1次、中位2.94毫秒。计时包含工具准备、指纹与内存审计，不含初始化、实际shell、人等待、落盘或模型/网络。该数据证实精确授权减少重复审批，不代表真实任务速度或安全提示自动通过。

调优：相同授权仅缓存指纹，不缓存路径/版本校验；有效调用只生成一次完整参数指纹，避免重复序列化与hash；审计流串行落盘，权限规则数量和日志均有上限。没有为速度缓存可变化的文件系统权限。

`npm run bench:agent`，100文件、5样本、零模型/网络延迟：两轮一次Glob，中位14.57毫秒（13.25–26.85），9个核心事件，内部请求4909/5808字符。规则提示与路径检查增加本地工作，不将跨模块耗时变化当作模型质量或费用改进。

人批准的shell仍具有当前用户的主机权限；文件范围、cwd和命令审批不是OS沙箱。文件路径复查不保证抵御任意主机并发攻击者的所有目录置换竞态。永久规则需明确编辑配置；scope只支持字面路径，受限子目录与递归查询相交时保守拒绝/审批，不自动排除它继续搜索。

审计只记录决策，执行成功/失败看工具结果；不能恢复或重放动作。选择项目内普通位置记录日志会增加禁止范围，建议项目外或已存在的`.mewcode/audit/`。日志最多10000条，规则最多400；会话授权仅当前执行器/进程有效。fork是权限接口，实际子Agent调度、总体预算池、Hooks和交互Slash模式切换待相应模块实现。
