## 万文件搜索与调优

`npm run bench:tools`生成固定10000个UTF-8小文件（src/noise各5000）及1个应排除的依赖文件，在中文临时目录中逐场景采样3次。每个稀疏场景准确返回5个目标，广泛匹配截断在200条。下表为Windows同一Node/rg版本的本地暖文件缓存样本，不含生成夹具、安装或真实模型耗时。

| 场景 | 中位耗时 | JSON结果大小 | 截断 |
| --- | --- | --- | --- |
| Glob全树稀疏匹配 | 120.24ms | 392 bytes | 否 |
| Glob限定src稀疏匹配 | 59.73ms | 392 bytes | 否 |
| Glob广泛匹配 | 98.10ms | 10500 bytes | 是 |
| Grep全树稀疏匹配 | 416.37ms | 1064 bytes | 否 |
| Grep限定src稀疏匹配 | 223.01ms | 1064 bytes | 否 |

优化前Glob限定src仍遍历全树，单独运行基线116.33ms；从固定目录前缀起步后59.73ms，约下降48.7%。全树场景保持约120ms。Grep建议显式path限定目录；fileGlob通过rg文件类型作初筛、项目相对路径匹配作复核，避免包含型glob覆盖.gitignore规则。前后场景相同，但独立临时目录、文件系统缓存与单机采样仍有波动，不能外推到所有仓库。

最终M03生产安装样本：help七次中位46.92ms（45.03–50.63ms），入口7052 bytes，编译JS合计82506 bytes；安装包73237 bytes，解压268023 bytes。独立工具定义、读取与授权创建均通过。重依赖继续按需加载，工具模块不进入help/version启动路径。

## 当前限制

chat仍为M02对话，六工具需明确调用；模型自动工具调用在M04接入。权限为本次调用/模式基础策略，完整审批UI、持久规则、Hook和审计在M06后补齐。Glob不自动读取.gitignore，支持显式ignore；搜索范围、隐藏文件与结果上限均可查看Schema。

shell授权不是OS沙箱。默认PowerShell使用Job Object与taskkill，显式Windows Git Bash主要依赖taskkill，脱离父进程的程序需单独管理；恶意命令仍可能通过系统服务启动外部程序。文件版本检查避免普通并发编辑丢失，不能替代内核级路径隔离。macOS未人工验证；POSIX专属FIFO场景只在对应平台执行。
