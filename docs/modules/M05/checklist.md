## 基准与调优

`npm run bench:prompt`，Windows Node24.14.0，5次样本；夹具1102文件，其中102指令文件。只检查目标的3个祖先目录、加载2份指令，共46注入字节。计时包含发现+提示组装，不含夹具生成或模型/网络，OS缓存可能已热：新catalog中位4.93毫秒，同catalog缓存访问中位1.13毫秒。示例提示3207字符，估算1069token。

环境段删除与API工具定义重复的说明后，同一100文件Mock Agent夹具的内部请求JSON从4636/5535字符降为4459/5358，每轮减少177字符；API工具定义本身保留完整描述。单任务复用工具定义，按需发现不扫描无关目录，普通CLI对重复诊断去重显示。

`npm run bench:agent`，5次、零模型/网络延迟：两轮一次Glob，中位8.50毫秒（8.28–19.78），9个事件（增加prompt_info）。该基准不代表真实模型延迟或成功率，也不把跨运行的耗时差当作提示质量提升。

## 已知边界

本模块是可复现的指令/协议/权限回归，并未测量真实模型成功率和费用。作用域优先级通过提示表达，硬权限通过执行器保证；不宣称提示文本可以强制模型遵守所有项目风格。

指令是单任务快照；不自动发现项目根之外的用户/global指令，不实现AGENTS.override.md，不能从任意shell命令字符串推导真实访问目录。过长规则仅注入前缀并警告，已知凭据和常见形式脱敏不等于通用secret识别。发现新scope可能多用一轮模型调用；现有预算仍生效。
