# M10：Slash Command

状态：已完成并推送，本地完整检查、Windows/Linux CI与独立安装包通过（2026-10-06），实际结果见[验收记录](checklist.md)。

命令只解析原始用户输入，注册名称、说明、参数和执行行为。执行结果分为本地状态、文本任务、Agent 任务移交。模型回答、工具/MCP结果、记忆和模板展开后的文本不会重新解析为本地命令。核心命令与模板模块不依赖 CLI/Ink。

| 命令 | 行为 |
| --- | --- |
| `/help [name]` | 查看帮助；`/help --refresh` 重建自定义模板索引 |
| `/clear` | 清空 chat 模型上下文、当前展示和 usage，不删除 Agent 持久会话 |
| `/model [name]` | 查看或切换当前 provider 的模型；不查询远端目录，不验证模型可用性，不持久化配置 |
| `/permissions [mode]` | 查看模式、启动权限上限、规则来源；可切换 plan/default/accept-edits，但不超过启动权限上限 |
| `/compact` | 对 chat 历史作本地有界摘录，不调用模型；保留原始问题和最近消息，明确可能丢失细节 |
| `/resume <id> [task]` | 交给现有 Agent 会话恢复流程；保留调用编号、动作摘要、预算和不确定状态，不重放旧动作 |
| `/plan [on\|off]` | 收紧至 Plan，或在启动上限允许时恢复 default；chat 始终是纯对话 |
| `/plan <task>` | 交给只读 Agent 执行任务；保留原权限 deny/ask 规则 |

`chat` TTY 支持上述命令和 Tab 名称补全；多候选显示名称，单候选补全并追加空格。最新20轮在可更新视图中展示，最多200轮后需要 `/clear`，让清空操作同时更新界面与模型上下文。不会宣称擦除终端 scrollback、系统剪贴板或模型服务历史。

`chat` 单次参数和管道输入同样解析命令。本地命令不会创建模型连接，缺少真实 API key 时仍可查看帮助或清空空会话。`run` 支持帮助、模型/权限查询、Plan 和恢复入口及模板展开；其单任务入口没有可清空/压缩的 chat 历史，所以 `/clear`、`/compact` 明确拒绝。JSON 模式的本地结果为 JSON 对象，Agent 任务仍输出原 JSONL 事件。

TTY chat 的 `/plan <task>`、`/resume <id>` 先退出并卸载 Ink，随后启动原 Agent CLI 和 readline 审批，避免两个输入控制器争用 stdin。移交不会自动把纯对话历史转换为 Agent 工具历史，也不会自动保存新任务。恢复校验项目、provider/model、所有者模式和快照完整性。任务结束后本次程序退出；再次运行 `chat` 可开始新对话。

自定义模板目录为 `<userDirectory>/commands/*.md` 与 `<projectDirectory>/commands/*.md`，默认分别位于用户和项目的 `.mewcode/commands/`。文件名即命令名：小写英文字母开头、英文字母/数字/横线，1–48字符，不递归扫描。优先级为内置 > 项目 > 用户。每个目录最多128个条目，文件最多64KiB；超限或坏元数据使用固定错误，不回显源正文。

可选 frontmatter 只接受字符串 `description`、`argument-hint`，每项最多256字符且不含控制字符；头部最多4096bytes。没有 frontmatter 时使用默认说明。启动/帮助仅读取每个候选文件最多4096bytes前缀；正文在明确调用时读取，并每次校验路径、大小、编码、权限和已知敏感值。索引缓存到 `/help --refresh` 或进程结束，修改正文下次调用生效，名称/描述变更需刷新。失效刷新报错，旧缓存不因此成为新的成功索引。

```markdown
---
description: 检查指定文件
argument-hint: '<path> [options]'
---
请检查 $1，并按以下要求给出建议：$ARGUMENTS
```

双/单引号用于把含空格文本分成一个参数，引号不传入 `$1`–`$99`；反斜杠保持原样，不提供 shell 转义语义。`$ARGUMENTS` 保留原始参数串。位置参数缺失或为空时报错；仅进行一次替换，插入的 `$2`、`/permissions`、`$(...)` 都是普通文字，不执行 shell 或本地命令。不支持 frontmatter 命令执行、脚本、环境展开或参数自动审批。原始输入/展开后任务最多256KiB、最多64个参数。

项目内模板使用现有 ReadFile 读取策略检查，ask/deny 来源不自动读取；项目外用户目录是显式用户模板来源，仍拒绝链接/junction、硬链接、无效 UTF-8、超限和已知密钥。已知 provider key、常见 `sk-` 与私钥正文不会注入模板或帮助。自定义命令不能修改权限；`run` 模板后续动作走原工具执行器。文件系统校验不构成 OS 沙箱，也不宣称抵抗所有非合作进程的目录替换竞争。

生成期间 Ink 拒绝新提交，Esc 取消模型、Ctrl+C 退出。命令注册器对异步解析/压缩持有互斥标记；Conversation 的清空、模型切换和压缩也拒绝生成期间调用。工具执行器在工具执行/审批期间拒绝模式切换；Slash Command 不作为 y/s 审批答案，不排队重放。当前没有常驻 Agent TUI，工具任务执行时使用原 CLI，而不是在审批输入中消费新的 Slash Command。

验收覆盖中文/引号/空参/未知命令、互斥与取消、模型切换、清空界面及上下文、压缩、真实会话恢复移交、同名优先级、按需读取/刷新、目录与文件边界、权限上限及审批竞争、模板不重新解析、CLI与独立安装包。基准使用固定100文件与7次采样，记录索引/展开/解析耗时与读取字节，无额外模型调用。
