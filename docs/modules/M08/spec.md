# M08：上下文管理

状态：已完成本地、Windows/Linux CI完整回归及独立安装包验收（2026-10-06），实际记录见[验收清单](checklist.md)。范围为 Agent `run` 的任务上下文和可选持久会话；chat 界面的会话管理不在本轮扩展。

## 约定

- 配置模型窗口、输出预留、触发比例、近期轮数与摘要/工具结果上限。窗口预算按序列化请求的 UTF-8 字节保守估算并明确标记，不将估算当作真实 tokenizer；费用累计优先采用 provider usage。
- 系统提示和项目指令每次恢复按当前环境重新生成，原始目标与最新后续目标保留完整；旧工具组只能整组归档，不能拆开 assistant toolCalls 与结果。近期轮次保持完整。摘要是低优先级的历史数据，不能变成权限规则。历史原文与完整调用链保留在压缩前检查点，模型上下文仅保留有界摘录和近期完整链。
- 第一版使用本地结构化摘录，保留调用编号、工具、结果状态、简短证据与溢写索引；不调用模型生成摘要，摘要费用为0。不能保证保留全部语义，完整旧历史保留在持久检查点中供显式查看。
- 长工具结果在启用保存时写入会话内 outputs；模型获得有界预览、错误状态和保留的文件revision，以及 digest/bytes索引。未保存时按有界内联结果回退，不虚构可读溢写路径。
- 持久保存显式使用 `run --save-session`；恢复 `run --resume <id>`。会话绑定规范项目根及 provider/model。恢复不继承批准缓存、不提升模式、不恢复MCP连接；新连接仍需显式选择与审批。初始模式与每次检查点中的收紧模式均形成恢复上限。持久规则重新加载当前配置，不将历史摘要还原成权限配置。
- 工具执行前持久保存意图，完成后持久保存结果。崩溃恢复的未完成调用补充“不确定/未重放”结果，旧callId和旧修改动作指纹不能再次执行；不宣称外部动作与本地记录实现了跨系统事务。
- `sessions list/show/compact/result/delete` 不调用模型。手动/自动压缩均生成候选、校验完整调用链、保存不可变检查点和原子提交记录后才切换内存；保存失败保留旧上下文并停止后续动作。
- JSONL包含schemaVersion、递增sequence、检查点引用与digest；尾部未提交记录不用于恢复，中间损坏/版本错误拒绝。使用独占会话锁；进程崩溃留下的锁需显式核对后解锁，不猜测锁已经失效。
- 会话目录必须具有本项目归属标记，禁止链接/路径穿越/任意文件清理。删除仅清理已验证归属且未锁定的单个会话，包含outputs；凭据在日志、检查点及溢写中脱敏。限制会话/记录/单文件大小，磁盘写入失败不能继续执行工具。

## 验收与调优

用模拟provider、临时目录和本地MCP夹具验证压缩、100轮、失败回退、完整调用链、JSONL损坏、取消、崩溃恢复、修改动作去重、权限收紧、凭据脱敏、锁与删除归属。运行完整检查和打包、Windows/Linux CI；基准记录压缩前后体积、耗时、信息保留与额外模型费用（0）。

## 实际限制

JSONL最多4MiB，检查点/溢写各2MiB，会话总64MiB/10000条提交，消息4096条/调用10000次。每次保存检查点包含当前上下文快照，较长任务可能先达到存储上限；不会删除历史以继续执行。局部磁盘错误停止动作，不宣称全机器断电或多个拥有主机权限的进程攻击下的事务保证。已知凭据、常见私钥形式脱敏，业务正文不是匿名化数据。

动作去重使用工具名与规范化完整参数SHA256；修改相同参数会被阻止，参数变化仍需新的审批且可能产生新的副作用，不能识别所有语义等价的shell命令。`ACTION_UNCERTAIN`表示需核对，不代表调用未执行。未启用持久保存时不提供完整历史或溢写恢复能力；chat仍采用原有有限会话行为。macOS、真实模型长会话和磁盘压力/断电未测试。
