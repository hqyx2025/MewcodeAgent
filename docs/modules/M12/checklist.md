## 延迟基准

`npm run bench:hooks`，本地相同Windows/Node，固定ReadFile文件、1个Pre与1个Post脚本，7次顺序采样；审批立即批准、不计人工等待，不写审计文件，不访问网络/模型；文件缓存与Node启动预热未控制。

| 指标 | 实测 |
| --- | ---: |
| 无Hook工具中位数 | 1.735ms |
| 含Pre/Post工具中位数 | 66.098ms |
| Hook事件 / 实际脚本启动 / 审批回调 | 14 / 14 / 14 |
| 14次Hook累计延迟 | 458.505ms |
| 额外模型请求 | 0 |

默认空配置走原执行路径，不创建脚本进程；仅执行匹配的事件/精确tool项。同一事务按Pre→工具→Post排序；保留新脚本启动和完整校验，避免通过跨事件授权/常驻进程缓存省略安全检查。本指标是简单本地脚本的延迟基线，不是任意业务脚本或人工审批的耗时承诺。
