# M09：记忆系统

状态：本地完整检查与独立安装包通过，Windows/Linux CI待核对（2026-10-06）。

用户记忆为 `<userDirectory>/memory.md`，仅保存显式确认的通用偏好；项目记忆为 `<cwd>/.mewcode/memory.md`，保存偏好、约定与用户确认的事实，绑定规范项目根。每个文件最多64KiB/100条，单条文本最多1024字符。文件是带版本、归属、来源的JSON代码块Markdown；不解析任意Markdown为可信记忆。

通过 `memory list/show/add/edit/delete/candidates/accept/unlock` 管理。新增、编辑、删除与遗留锁解除通过隐藏管理工具及现有权限执行器；即使accept-edits也需确认，Plan禁止变更，deny优先。模型不拥有这些隐藏工具。读权限使用 `MemoryRead`，不自动读取ask/deny来源。普通文件工具不能直接读取或修改内部记忆文件。

会话候选仅提取原始user消息中明确标记的单行 `用户偏好：`、`项目约定：`、`已验证事实：`，不从模型或工具文本猜测事实，不把临时任务自动固化。候选本身不写入文件，接受时记录会话/检查点/消息/行号；“事实”仍是用户复核确认，不宣称机器证明。会话摘要不提取，跨项目会话拒绝。

候选提取使用当前或显式指定的不可变检查点，最多100条并报告过滤/省略；接受以候选digest绑定来源和正文。候选/管理CLI不调用模型，也不在run结束后自动写入；单条确认入口先保留可审阅的最小流程。

确认后去重；更新使用文件revision、独占锁与原子替换，审批期间变化拒绝，不静默覆盖。锁不自动偷取，显式unlock仅允许同主机且原进程已终止。只处理指定记忆文件和自身临时文件，不删除目录。读取拒绝链接/junction、硬链接、损坏、未知版本、无效UTF-8和超限；错误不回显源正文。已知凭据、常见密钥及敏感赋值拒绝持久化，已有文件的敏感条目不注入或输出。

Windows路径规范化先验证逐级无链接，再处理临时目录短路径别名。自定义项目内用户目录对普通文件工具加deny，可能使广范围递归查询被拒绝；Shell/MCP的授权主机能力不是OS沙箱。敏感过滤不是完整个人/业务信息识别器；并发revision/锁避免合作写入丢失，不宣称防御所有外部文件系统竞争或断电事务。

run/prompt与chat使用独立记忆数据段。偏好/项目约定优先；事实只按词项交集筛选（中文使用二字词项），整条选入，不截断条目；总JSON注入预算默认8192bytes，可禁用。每轮重新读取并选择，压缩保留当前system，恢复重新生成system；删除后下一次请求不再加载。历史中模型复述过的内容不能据此抹除，不宣称向量级检索或语义无损。

验收：跨会话加载、跨项目隔离、候选不自动保存、确认/拒绝/Plan/deny、去重/编辑/删除、revision竞争、锁/故障、路径链接/穿越、密钥与恶意记忆、预算/筛选、压缩与恢复、CLI与独立安装包。固定100条记忆基准记录读取/筛选耗时、注入字节与本地保守token估算，额外模型调用为0；真实模型命中率另行验证。
