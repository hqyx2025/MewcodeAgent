# M16：整体评估、调优与发布准备

状态：实现中；沿用Node.js 24、TypeScript 5、ESM与npm锁文件。

交付包含可重复离线评估集、性能前后记录、架构复盘、故障恢复、依赖许可与安装升级/回滚说明。准备待发布安装包，不自动执行npm publish或创建正式Release。

固定评估仅在程序创建的归属临时中文/空格路径仓库内运行，使用脚本化provider，不读取用户项目或真实provider配置，不调用收费模型。覆盖真实工具修复确定性bug并执行Node断言、拆分文件重构后行为保持、100次工具轮次压缩与持久恢复、防重、实际MCP调用与连接关闭、两成员工作树修复/真实检查/汇总。结果以文件内容、断言退出码、状态和持久账本核验，不以模型completed判定正确。

评估作为npm run eval:release独立运行并输出JSON摘要，同一场景接入测试和CI。记录每场景时间、合成用量及实际断言，不将脚本化成功率解释为真实模型质量。完整check、独立生产依赖安装包与Windows/Linux/macOS CI分别验收；TTY/UI自动化验证与人工终端验收区分记录。

调优先测量现有基线，再改动最大的已确认重复工作；保留目标、完整近期调用组、历史指纹、权限和所有既有边界。使用相同固定场景复测；不添加未经测量的吞吐或内存达标承诺。检查启动、渲染、搜索、压缩、并发、内存和取消清理，复用既有模块基准与测试证据。

包内包含运行时依赖许可清单和实际许可证文本；版本来源锁文件并核对安装metadata，不把清单替代许可法律判断。独立安装验证bin、配置、资源、核心工具和协作能力。发布准备需离线评估、依赖边界、清洁构建和包内容核验；上传npm属于后续明确授权的动作。

升级保留配置/会话/记忆/工作树与交付分支，先停止活动任务并备份存储；回滚安装包只回滚代码，不回滚外部写入，遇到新格式先核对兼容性。禁止force清理或删除用户项目。已知限制和未完成的平台人工验证明确记录。
