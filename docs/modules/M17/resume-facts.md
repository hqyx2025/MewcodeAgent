# 简历事实素材与证据

这些句子描述仓库实际能力，不包含虚构的公司、任职、用户量、上线规模或求职成果。按自己真实参与情况、能现场解释的代码和岗位重点选择三到四条，不能将AI辅助完成的整仓能力直接当成个人独立贡献。项目来源与独立实现范围见[讲解稿](project-story.md)。

## 可选择的项目描述

**MewCode Agent｜TypeScript / Node.js / Ink / MCP / Git Worktree**

一个模块化CLI Coding Agent项目，支持流式对话、真实文件与Shell工具、统一权限执行、持久会话恢复及隔离任务协作。以固定离线评估和跨平台自动化验证工程行为。

## 不使用的表述

“生产环境上线”“数万用户”“任意任务100%成功”“无损压缩”“绝对安全沙箱”“全局exactly-once”“零内存泄漏”“整体速度提升30%”“token费用下降95%”均没有对应证据。只能表述测得的局部场景和实现边界。也不能写“已发布npm”：当前是待发布本地包，正式发布仍有许可和人工体验待办。

## 面试前准备

选定一条自己熟悉的实现，沿[问答](interview-questions.md)打开源文件，运行[演示](demo-guide.md)，解释一次失败为什么没有副作用、一次取消为什么保留已完成修改。对没有亲自确认的优化、模型能力或平台体验明确给出已有证据与未知部分。真人试讲及岗位定制由用户完成，本轮未记录口述时间或求职结果。
