# M15：Agent Teams

状态：已实现，正在完成验收。Node.js 24、TypeScript 5、ESM、npm，依赖沿用锁文件。

团队是持久化成员、预声明依赖任务与消息看板。成员绑定唯一归属工作树，身份和交付跨运行保存；每项任务使用独立模型上下文，继承角色、必要依赖摘要和有界消息，不复制整个父历史。协调者是确定性调度器，不增加协调者模型调用。

入口为 `teams create/add/show/list/send/inbox/run/cancel/retry/recover/unlock/report`。管理和执行注册到统一工具权限入口；Plan仅查看。成员只开放受限文件工具、明确选择的Bash、TeamSend/TeamInbox，不能创建任务、提升权限、再次委派或合并。模型消息是数据，不能授予权限或触发新的执行任务。

每团队最多4成员、32任务、128持久消息；默认并发2、总预算60k、每任务预算40k、每任务6轮/30秒。实际执行仍取可信subagents配置和当前CLI限制的更小值。同成员任务不并行，同工作树不分配给多个成员；依赖只接受存在且无环的任务。

领取在归属锁内写入唯一claim/agentId、attempt和预算预留，执行前落盘；已交付任务不重复领取。失败依赖递归阻塞后续任务，不影响独立分支；达到可信每批maxTasks上限时未执行任务保持queued。重试必须用户明确指定失败/取消/不确定任务，最多3次尝试。取消传播到运行任务，停止领取；消息不能触发无限调度。预算不足可能使任务失败或留在queued，run任一非completed退出1，需要核对后再明确执行。

成员已有交付的工作树仅允许核验同成员上次agentId、原基准和归属后继续编辑；保留修改，拒绝借用其他agent的工作树。长期成员不表示后台守护进程或无限会话。Bash仍具有当前用户主机权限，工作树不是OS沙箱。

消息使用messageId与内容指纹去重，相同ID不同内容拒绝；发送身份由可信运行claim决定。单消息≤1024字符，单发送者（含coordinator）最多16条，默认团队消息上限64。任务开始最多选择8条/2KiB消息；延迟消息保留到后续明确运行。总上下文为合法JSON，原context缩至1024bytes、最多8依赖的摘要各256bytes；序列化超过4096字符时省略消息并标记计数，仍超限则继续缩减context与依赖摘要并标记truncated，计入控制字符的JSON转义扩展。领取已选择消息按claim标记，省略不自动重投；TeamInbox最多返回最近8条并标记省略。TeamInbox只读，不以读取提升权限或启动任务。

每个运行持久化主机/pid/runId与正在执行的预算预留。只允许原进程已确定停止后的recover/unlock；恢复前核对成员工作树，不自动续跑未知写入。不确定任务变uncertain，保守计入已落盘预留额度，任务需明确重试；已完成结果保留，不获得新的免费预算。

报告保存实际子任务状态、用量、观察证据和工作树检查；按各成员diff列出变更、冲突与同名路径重叠，不自动合并。completed/观察证据/退出码不能证明任务语义正确。默认测试使用模拟provider和归属临时仓库，不调用收费模型。

记录位于主仓库外 `<storageDirectory>/teams/<commonDir哈希前24位>`，严格归属marker、每仓库最多64团队、单记录512KiB，输入文件最多32KiB。进程内FIFO和跨进程归属锁保护原子更改；拒绝非空无marker目录、链接、损坏JSON、重复身份/领取及消息指纹不一致。状态不是加密或签名，不能防御当前主机用户任意同步篡改多个归属记录。Windows原子rename遇到短暂共享冲突时最多5次指数退避，每次核对旧内容，不删除目标或强制覆盖。

主要错误为TEAM_INPUT/OWNER/BUSY/WORKTREE/MESSAGE/DUPLICATE/LIMIT/RETRY/SENSITIVE，权限与预算沿用TOOL_PERMISSION/TOKEN_BUDGET。源JSON和密钥不回显；输入与结果保存前校验敏感模式/已知凭据。运行异常保留run/claim线索，活进程不允许抢占；需停止原进程后明确恢复，不保证Git操作与看板写入具备跨文件原子事务。默认show省略目标/上下文/消息正文，仍显示生成摘要和观察引用。CLI管理入口是 `teams run`，未开放模型自动创建团队或 `run --teams`。

验收：依赖顺序与独立并行、重复领取/消息、失败与阻塞、取消、明确重派、恢复防重、工作树冲突、预算跨运行累计、权限与源文本脱敏、CLI和独立安装包。测量调度时间、成员忙闲时间、消息数、请求数与合成token，写明平台和模拟条件。
